# Security policy

## Supported versions

Only the latest major version of Pheme receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Report it privately through GitHub:
[Security → Report a vulnerability](https://github.com/dawid1103/Pheme/security/advisories/new).

Include the affected package and version, what an attacker can do, and the steps or code to reproduce it.

Pheme is maintained by one person in spare time. Reports are read and answered as soon as possible, with no guaranteed
response time. A confirmed vulnerability is fixed in a new release and credited in the advisory, unless you prefer
otherwise.
